# Nguyen Thanh Nghia - Game Developer Portfolio

Interactive Three.js portfolio for a Unity/Game Developer CV. The site is designed as a lightweight career hub: walk a 3D character through project stations, inspect selected game projects, and access CV/contact links quickly.

The player model uses Kenney's Blocky Characters pack under Creative Commons CC0. See `public/assets/vendor/kenney/blocky-characters/README.md`.

## Local Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The production output is generated in `dist/` and can be deployed to GitHub Pages.
